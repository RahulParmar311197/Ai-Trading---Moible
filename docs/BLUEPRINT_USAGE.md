# Blueprint Usage

`AI_TRADING_PLATFORM_BLUEPRINT.md` must be reviewed before each implementation milestone together with `PROJECT_STATUS.md`.

The status tracker records what has actually been implemented. The blueprint defines what the platform is intended to become. Do not mark a capability complete merely because its folder, interface, or placeholder exists; completion requires implementation and relevant validation.

When requirements conflict or a detail is missing from the repository copy, consult the original detailed project blueprint before making an implementation assumption.
